# Bedrock Check — проверка отчетов

Автономная страница для проверки цифровой подписи Ed25519 отчетов Bedrock Check.

**Developer: AbsurdEar7658**

## Включить GitHub Pages

1. Откройте [Settings → Pages](https://github.com/r32935621-netizen/BedrockCheck-verify./settings/pages).
2. В **Source** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
4. Дождитесь успешной публикации. GitHub покажет адрес страницы в этом же разделе.

Ожидаемый адрес после публикации: `https://r32935621-netizen.github.io/BedrockCheck-verify./`.
Точка в конце имени репозитория является частью адреса.

## Проверить отчет

Откройте опубликованную страницу с телефона. Загрузите `report.json` либо
вставьте весь текст. Если проверяющий заранее сообщил код сеанса, введите
ожидаемый код. Сверьте подпись, имя ПК, время и состояние сканирования.

Отчет проверяется локально в браузере: отправки файла на сервер, внешних
библиотек, аналитики и CDN нет. Нужен современный браузер с Web Crypto
Ed25519 и безопасный контекст HTTPS.

## Что опубликовано

- `index.html` — страница и публичный ключ проверки.
- `.nojekyll` — статическая публикация без обработки Jekyll.
- Этот README.

Исходники сканера и встроенный приватный ключ находятся в отдельном
приватном репозитории. В этот репозиторий они не копируются.

## Граница доверия

Приватный ключ встроен в ПК-программу и может быть извлечен из нее.
Действительная подпись подтверждает соответствие данных этому ключу,
но не доказывает честность сканирования или отсутствие читов.
Индикаторы требуют ручной оценки.

Публичный ключ страницы должен совпадать с версией сканера, создавшей отчет.
При смене пары ключей обновляйте страницу из `docs/index.html` сканера.
